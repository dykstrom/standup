## [5.2.0] - 2026-05-09

### Added

- Internationalization (i18n) support with English, German, and Swedish translations. Language can be selected in the Settings dialog. The UI reloads immediately on language change without restarting the application. OS locale is detected automatically on first launch.
- GitHub Actions matrix build covering Linux, macOS, and Windows on both x86_64 and arm64 architectures.
